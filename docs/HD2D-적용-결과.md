## 1. 지금 화면

- 보기는 **HD-2D 하나**예요(2D·3D 보기 단추와 3D 방식 메뉴는 없앴어요). 들판·마을·건물 안·바닷속 모두 `gl3d.js`가 그려요. WebGL이 안 되는 기기만 2D가 자동으로 대신해요.

## 4. 검증

- 이동: 방향키·W A S D·조이스틱이 화면 방향 그대로(위 = 북쪽). 칸 사이 자유 걷기 그대로.
- 충돌: 그림 판은 칸을 막지 않아요. 막힌 칸은 지도 그대로(건물 칸 수 = 막힌 건물 칸, 시험으로 확인).
- 가림: 판의 깊이 = 건물 앞줄 → 앞 칸 사람은 앞, 뒤 칸 사람은 뒤. 내 캐릭터를 가리면 둘레만 도트 무늬로 비쳐요.
- 상호작용: 문은 지도 칸 그대로(건물 앞줄 가운데). 건물·사람 누르기는 HD 카메라로 화면 → 지도 계산.
- 저장: 저장 내용은 바뀌지 않았어요(그래픽 품질은 브라우저에 따로 `dokdo-gq`).

## 5. 앞으로 필요한 것

### 3D 모델(GLB)이 있으면 좋은 것
지금 건물은 한 방향에서 본 그림 판이라 카메라를 돌릴 수 없어요(그래서 HD-2D 카메라는 북쪽 고정). GLB(낮은 폴리곤 + 도트 질감)가 있으면 돌려 볼 수 있어요.
1. 이야기 건물 4종(수호관·주인공 집·김박사 연구소·상점) — 지금은 비슷한 에셋 그림을 빌려 썼어요(이름표·간판이 없어요).
2. 독도 건물: 등대·독도경비대·서도 주민숙소 — 그림은 실제와 닮았지만 칸 폭에 맞춰 줄였어요.
3. 도동항 여객선터미널·여객선(바다 쪽에서 보는 컷신용), 아치형 해안 보행교(그림의 다리 방향이 지도와 달라 아직 안 씀).

### 새로 그리면 좋은 도트·그림
1. 이야기 건물 전용 정면 그림(간판 ‘수호관’·‘김박사 연구소’ 등) — 지금은 비슷한 건물 그림.
2. 건물 안 벽 그림(정면 벽지·창문을 처음부터 세운 벽 크기로) — 지금은 2D 벽 칸 그림을 1.5배로 늘려 붙여요.
3. 헬기장·출구 표시를 위에서 본 HD 그림 — 지금은 예전 땅 그림.
4. 억새(가을 길)·해국(독도) 전용 덤불 — 지금은 에셋팩 들꽃·초지 풀로 대신해요.
5. 캐릭터·우산몬 걷기 시트는 기존 것을 그대로 써요(참고 그림은 애니메이션 시트가 아니라 넣지 않았어요).

## 6. 망가진 것

- 이야기·퀘스트·결투·저장·건물 출입·배 타기·지름길 이동은 시험으로 끝까지 확인했어요. 망가진 것은 찾지 못했어요.
- 만드는 중에 찾아 고친 것: 셰이더 한 줄 가운데 넣은 주석이 뒤 코드를 꺼서 WebGL이 켜지지 않고 2D로 그려지던 것. 시험이 ‘WebGL이 없으면 건너뛰기’라 놓쳤어요 → 이제 시험 브라우저에서 WebGL이 실제로 켜졌는지 확인하고(흐름·화면 시험), 셰이더 줄 가운데 주석도 검사해요.
- 바뀐 점(망가진 것은 아니에요): 카메라를 돌리는 둘러보기가 없어졌어요. 예전 저장 파일은 그대로 열려요.
- 아직 아쉬운 점
  - 이야기 건물은 비슷한 에셋 그림을 빌려 써서 간판이 없어요(이름표로 구분해요).
  - 건물 안 벽 그림은 2D 벽 칸을 늘려 붙인 거라 조금 흐릿해요.
  - 시험 컴퓨터(그래픽 카드 없음)에서는 걷기가 느려서 화면 시험의 시간 한도를 늘렸어요.
