## 2. 바꾼 이름

- **상장군바위 → 지네바위 / 길 이름 ‘물골 오르막’**: ‘상장군바위’는 고시된 지명이 아니었어요. 바위 능선 모양(GLB)은 이름 없는 바위로 남겨 두었어요.
- **삼형제굴바위 해안 → 군함바위 해안**: 그 길은 코끼리바위(서쪽)와 물골(북서쪽) 사이라 실제로는 군함바위·넙덕바위가 있는 바다예요. 삼형제굴바위는 실제 자리인 서도 북동쪽(촛대바위 해안 북쪽)으로 옮겼어요.

## 3. 추정·남은 것

- 바위 모양: 숫돌바위·촛대바위·독립문바위·코끼리바위·삼형제굴바위·탕건봉은 에셋 팩 GLB, 보찰바위는 ‘모양 추정’, 지네바위는 일반 갯바위 모양(사진 확인 안 함), 군함바위는 지도의 바위 칸(바위 덩어리)이에요.
- 지도 한 장 안의 방향: 길 지도는 서쪽 출구 → 동쪽 출구로 이어지는 띠 모양이라, 실제 해안선 방향(예: 서도 동쪽 해안은 남북으로 길어요)과 다를 수 있어요.
- 코끼리바위는 실제로 서도 서쪽인데, 코끼리바위 마을 지도에서는 남쪽 만에 있어요(마을 지도 안의 방향은 고치지 않았어요).
