# 독도 탐험대 0.19 도트 자료

내장 image_gen으로 사용자 박사님 시트를 참고하여 새 PNG를 제작했습니다. 원본 생성 PNG의 투명도를 보존하고 게임에서 프레임 단위로 잘라 표시합니다. 최종 프롬프트는 art-v19-prompts.json에 있습니다.

## 파일

- dist/assets/characters/professor-atlas-v19.png: 1536×1024, 5열×3행. 정면/오른쪽/뒷면 각 정지+4보행. 왼쪽은 완전한 프레임을 좌우 반전합니다. 한여울 박사에게 적용합니다.
- dist/npc-atlases.js: 박사와 기존 주민의 프레임 경계·머리/발 기준점. 프레임별 크기를 늘리거나 팔다리를 변형하지 않습니다.
- dist/assets/scenery/korean-island-atlas-v19.png: 1254×1254, 연구소·수호관·상점 / 주택·소나무·돌 화단 / 기와 돌담·배·기록판.
- dist/assets/scenery/two-islands-monument-v19.png: 1346×1168, 독도의 두 섬에서 영감을 얻은 창작 조형물.
- dist/scenery-atlas.js: PNG의 실제 경계에 맞춘 잘라내기 좌표. 생성 결과의 간격이 균일하지 않으므로 단순 3등분을 사용하지 않습니다.
- dist/scenery.js: 비율 유지, 아래쪽 기준 정렬, imageSmoothingEnabled=false.

## 교체와 반영

PNG를 같은 경로에 교체할 수 있습니다. 레이아웃이 달라지면 위 좌표도 수정합니다. 모든 맵·NPC는 32px 지형 기준에 맞추고, 사람은 48px 표시 영역을 사용합니다. NPC 행동 반경은 출발 위치에서 한 칸이며 대화할 때 멈춥니다.

한옥과 소나무, 조형물은 실제 독도의 시설·식생을 재현한 자료가 아니라 기존의 창작 마을을 위한 장식입니다. 실제 독도 학습 자료와 구별합니다.

## 몬스터 로딩 수정

기존에는 PNG가 준비되지 않은 모든 경우 예전 절차형 몬스터 그림을 그렸습니다. 이제 로딩 중에는 중립적인 점 세 개만 표시하고 준비된 현재 PNG를 바로 그립니다. 실패할 때도 예전 디자인을 표시하지 않습니다. 이미지 성공·실패 모두 도감/대화/전투 캔버스를 다시 그리며 스타터·동료·현재 지역 우산몬의 정면/뒷면을 미리 읽습니다.

## 검증

이미지 로딩 전/성공/실패, 캐시 재사용, 정면/뒷면, 217개 활성 경로, 90개 NPC 포즈, 8지역 길찾기, 실제 렌더러의 맵/박사 포즈와 브라우저 플레이 화면을 확인합니다. 진행 데이터의 형식은 바뀌지 않습니다.
