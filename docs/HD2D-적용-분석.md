# HD-2D 적용 분석 (v0.79)

HD-2D 에셋팩을 넣기 전에 기존 코드를 읽고 정리한 내용이에요. 결론부터: **그리기만 바꾸고 게임 규칙(좌표·충돌·이야기·퀘스트·전투·저장)은 건드리지 않아요.**

## 1. 기존 구조

| 부분 | 파일 | 하는 일 | HD-2D에서 |
|---|---|---|---|
| 지도 데이터 | `maps.js` | 글자 그림(한 글자 = 32×32 한 칸) → 칸 종류(grid), 막힌 칸(solid), 건물·구조물·장식, 출구·도착 자리, 층(levels: 0~9층, 한 층 32) | **그대로** |
| 지도 객체 | `world.js createMap` | grid + 얕은 물(shallow)·꽃 자리 등 | 그대로 |
| 충돌 | `world.js blocked()` · `game.js freeBlocked()` | 칸 단위. 막힌 칸(solid), 건물(5)·조형물(7)·방(8·9), 물은 나만 들어가요(얕은 물 걷기·깊은 물 잠수). 자유 걷기는 몸이 걸치는 칸을 모두 검사 | **그대로** — 그림은 충돌에 영향 없음 |
| 길 찾기 | `world.js pathfind()` | 칸 BFS | 그대로 |
| 높낮이 | `maps.js applyHeights` · `heights.js` | 층 경계 = 절벽 면(막힘), 길이 지나면 계단(반 층) | 그대로(3D 땅 높이도 이 값을 그대로 써요) |
| 캐릭터 | `characters.js` · `world.js paintActor` | 64×72 시트(걷기 5장), 게임에 48 높이로 | **그대로**(3D 공간에 세운 판으로) |
| 2D 그리기 | `world.js drawWorld/drawActors` | 땅 타일 그림 + 발끝 깊이 순 | 그대로(2D 보기) |
| 예전 3D | `game.js` 3D 분기 · `box3d.js` | 땅을 줄마다 눕히고 먼 것부터 덧칠 | 그대로(메뉴에서 고를 수 있어요) |
| 새 3D | `gl3d.js` (v0.77~) | WebGL 메쉬·깊이 버퍼·셰이더 | **여기에 HD-2D를 얹어요** |
| 이름표·누르기 | `game.js toScreen/fromScreen` | 화면 ↔ 지도 | HD-2D 카메라 식으로 바꿔 계산 |
| 저장 | `engine.js validateSave` | 지도 id·칸 x,y·진행·동료 | 그대로(그래픽 설정은 브라우저 localStorage에 따로) |
| 건물 안 | `interiors.js` | 2D 방 | 그대로(건물 안은 2D) |

## 2. 위험요소와 대응

1. **그림과 충돌 칸이 어긋남**: 에셋 PNG는 원근이 들어간 그림이라 바닥 모양이 지도 칸과 딱 맞지 않아요. → 충돌은 지도 칸을 그대로 쓰고, 그림은 건물 칸의 **앞줄(문 줄)에 바닥을 맞춰** 세워요. 그림이 칸보다 조금 넓어도 막힌 칸은 늘리지 않아요.
2. **캐릭터가 건물에 묻힘**: 건물 그림을 카메라와 수직인 판으로 세우고 바닥 선을 건물 앞줄에 두면, 깊이 버퍼가 “건물 뒤 칸에 선 사람은 가려지고, 앞 칸에 선 사람은 보이게” 정해요. 건물 안 칸은 막혀 있어서 사람이 판을 지나가지 않아요. 내 캐릭터를 가리면 그 둘레만 도트 무늬로 비쳐 보여요.
3. **카메라 회전**: 건물 PNG는 한 방향에서 본 그림이라 돌리면 납작해요. → HD-2D 시점은 카메라 방향을 **북쪽을 보는 쪽으로 고정**(옥토패스처럼). 돌려 보고 싶을 때는 ‘새 3D · 뒤에서 따라가기’(상자 건물)를 써요.
4. **픽셀 밀도**: 에셋은 고해상도 채색화, 캐릭터는 48 높이 도트. → 가져올 때 게임 크기로 줄이고, 색 수를 줄이고, 투명 경계를 0/255로 자르고, 바깥에 1픽셀 어두운 테두리를 둘러 도트 그림과 맞춰요(원본은 손대지 않아요).
5. **이름과 그림이 다른 파일**: 04 폴더 일부(예: `05_석재_계단_01`은 해식동굴). → 분류는 그림 내용 기준(`docs/HD2D-에셋-분류.md`).
6. **한글 파일명**: 오프라인 한 파일 판은 영문 그림 이름만 모아 넣어요. → 가져온 그림은 한 장의 그림 모음(`scenery/hd2d-atlas.png`)과 영문 이름으로.
7. **성능(학교 태블릿)**: 그래픽 품질 3단계(낮음·보통·높음): 그리는 해상도, 그림자, 화면 효과, 물결.
8. **바닷속**: 새 3D는 아직 바닷속을 그리지 않아요(잠수하면 예전 3D로).
