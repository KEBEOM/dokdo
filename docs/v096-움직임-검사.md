# v0.96 요청 01(걷기·수영 움직임) 검사 — 적용 보류

받은 움직임 그림 32장을 지금 걷기 그림(characters/explorers-v2-64x72.png, 방향마다 5장)과 칸마다 맞대 봤어요.

- 새 그림은 새로 그린 장면이 아니라 **지금 그림 5장을 순서만 바꿔 다시 쓴 것**이에요. 걷기 8장 = 0·1·2·3·4·3·2·1(왕복), 수영 6장 = 앞 6장, 잠수 = 걷기와 같은 그림.
- 지금 그림의 차례는 0(서기)·1(한쪽 다리 내딛기)·2(모으기)·3(다른 다리 내딛기)·4(모으기)예요. 왕복 차례로 돌리면 3번(같은 다리 내딛기)이 두 번 이어져 **같은 다리로 두 번 걷는 모습(뒷걸음질처럼)**이 돼요.
- 장마다 몸이 2~3px씩 좌우로 옮겨져 있어서(발 맞춤 보정) 걸을 때 몸이 흔들려 보여요.
- 물에 들어가면 허리 아래를 감추는 것(물선 y=46)은 지금도 3D 화면에서 몸을 물낯 아래로 14px 내려 같은 효과를 내고 있어요.

그래서 이번 버전에선 움직임 그림을 바꾸지 않았어요. 8장 걷기를 쓰려면 1→2→3→4 사이에 새로 그린 중간 장면(사이 그림)이 있어야 해요.
