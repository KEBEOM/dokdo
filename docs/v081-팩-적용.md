팩의 `CLAUDE_COMMAND_KO.md`에 따라 **에셋 제작·형식 검증(팩에서 완료)** 과 **게임 연결·실행 검증(이번에 한 것)** 을 나눠 적어요.

## 1. 게임에 연결한 것

- **PNG 처리**: 4배 원본을 미리 곱한 알파로 줄였어요(LANCZOS). 색 수를 줄이고 알파를 0/255로 다시 잘랐어요. 최종 1배 크기에서만 1px 테두리를 붙였어요(캔버스를 1px씩 넓히고, 아랫줄 1px을 땅 밑으로 내려 발 자리를 맞췄어요).
  - 실내 타일은 꽉 찬 사각형이라 테두리를 붙이지 않았어요.
  - 처음 한 번만 가공해서 그림 파일로 넣었고, 매 장면마다 줄이지 않아요.
  - `checks/`·`previews/`는 읽지 않아요.
- **선착장 칸 해석**: 1·2 칸은 **바닥은 이어 두고 설치물만 비웠어요**(팩의 해석 그대로, 안내판·사람은 기존 게임 것). 3 칸과 출구 a·< 칸에는 모델이 없어요. 걷는 칸·충돌은 지도 그대로예요.
- **이야기 시설 표시**
  - 독도의 수호관·연구소·상점·집 문 앞 안내에 ‘· 이야기 시설’을 붙였어요.
  - 동도 연구소는 v0.81의 실제 등대 모델 대신 이야기 시설 그림으로 바꿨어요. 실제 등대의 역할과 섞지 않기 위해서예요.
- **추정 표시 유지**: 바위 지명 말 걸기의 아래 줄을 바꿨어요.
  - 보찰바위: ‘바위 모양은 추정’
  - 상장군바위: ‘게임 속 임시 이름 · 바위 모양은 추정’
  - 한반도바위: ‘사진 한 장을 참고한 단순한 모양’
- **충돌**: 그림 알파나 모델 상자를 쓰지 않고 지도 칸 그대로예요.

## 3. 확인하지 못한 것

- **저사양 모바일 실제 기기 프레임 속도**: 시험 컴퓨터에 그래픽 카드가 없어(소프트웨어 WebGL) 실제 기기로 재지 못했어요. 소프트웨어 WebGL에서는 ‘낮음’ 품질로 15~18프레임이에요.
- **바위 실물 형상**: 팩에 적힌 대로 추정이에요(보찰·상장군은 일반 바위 대체, 한반도·천장굴은 사진 한 장 참고).
- **식물 동정**: 식생 특징을 단순화한 그림이에요. ‘바닷가 풀’은 갯제비쑥으로 확정하지 않았어요.
