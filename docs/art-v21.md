# 0.21 마을·지형과 건물 겹침 수정

바다, 잔디, 풀숲, 흙길, 모래, 부두를 청록·올리브·모래·목재 계열로 통일했습니다. 건물의 두꺼운 검은 테두리를 줄이고 재료별 어두운 색 외곽선을 사용합니다. 태극기와 태극 문양은 넣지 않았습니다.

## 이미지 교체

- `dist/assets/scenery/village-pixels-v21.png`: 투명 1254×1254 PNG. 3열×3행, 연구소/수호관/상점, 집/나무/화단, 담장/배/팻말. 원본은 수정하지 않고 `scenery-atlas.js` 좌표로 각 물체를 한 번 잘라 그립니다.
- `dist/assets/scenery/terrain-pixels-v21.png`: 1024×1536 PNG. 위 행 바다/잔디/풀숲, 아래 행 길/모래/부두. `terrain-atlas.js`가 채취 영역을 정의합니다. 32픽셀 지형 타일에 연속 좌표로 적용합니다.
- `two-islands-monument-v19.png`: 기존 두 섬 조형물 유지.
- 그림 위치나 크기를 바꾸면 atlas의 좌표도 수정하세요. 단일 HTML에는 이미지가 포함되므로 다시 빌드해야 합니다.

## 표시 방식

집은 지형 타일로 찍지 않습니다. 건물 한 채 전체를 캐릭터와 같은 고해상도 오브젝트 레이어에서 그립니다. 건물·나무·배·담장과 캐릭터의 발밑 위치를 함께 정렬하여, 건물 뒤의 사람이 지붕 위에 올라온 듯 보이던 오류를 수정했습니다. 실제 벽의 이동 차단과 출입구 앞 경로는 유지합니다.

지형은 현재 지역 한 장만 캐시하며 이미지 로딩 완료 시 다시 그립니다. 해안 거품은 네 방향에 표시하고 부두 연결면에는 그리지 않습니다. 풀은 세로로 뒤집지 않습니다.

이 마을 배치는 창작 공간이며 실제 독도의 시설 배치를 나타내지 않습니다. 생성 프롬프트는 `art-v21-prompts.json`에 있습니다.
