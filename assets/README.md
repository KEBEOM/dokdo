# 독도 탐험대 이미지

`image-catalog.html`을 브라우저로 열면 캐릭터 이름, 그림, 교체할 파일 경로를 한눈에 볼 수 있습니다. `image-list.csv`는 전체 목록입니다.

게임 프로젝트의 `assets` 폴더 안에서 원하는 PNG를 같은 이름으로 덮어쓰고 `index.html`을 새로고침하세요. 이미지 팩만으로는 게임이 실행되지 않습니다.

- `monsters/001.png` ~ `100.png`: 정면, 도감, 지도, 상대 그림. 128×128 투명 PNG 권장.
- `monsters/back/001.png` ~ `100.png`: 전투 중 내 동료 그림. 기본은 정면의 좌우 반전이므로 직접 그린 뒷모습으로 교체 가능.
- `monsters/100.png`: 전설의 강치 독도몬 해랑.
- `player/`: 위·아래·왼쪽·오른쪽 × 걷기 자세 2장. 64×64 투명 PNG 권장.
- `npc/01/` ~ `npc/08/`: 지역별 인물. 64×64 투명 PNG 권장. 파일과 이름은 목록에서 확인.
- `scenery/`: 연구소·수호관·쉼터·집·나무. 원본 PNG와 같은 크기로 제작.
- `monster-contact-sheet.png`: 100종 번호별 미리보기. 게임에서 사용하지 않는 참고 그림.

기존 교체용 PNG 273장과 새 탐험대원 원본 4장으로 총 277장입니다. NPC와 생물 계열은 기본 도트 형태를 공유합니다. 독도몬은 진화형을 포함해 100종입니다. 지면 타일·기록판·배 등은 아직 Canvas 코드로 그립니다.

파일이 없어도 기본 도트 그림으로 표시됩니다. 가로세로 비율은 유지되므로 투명 정사각형 안에 그림을 넣는 방식이 편합니다. 건물의 이동 가능 범위는 그림을 바꾸어도 그대로입니다.

단일 실행 파일 `dokdomon-play.html`에는 그림이 내장되어 있습니다. 새 그림을 반영하려면 게임 폴더에서 `node build.mjs`를 다시 실행하세요. 폴더형 `index.html`로 플레이할 때는 PNG 교체 후 새로고침만 하면 됩니다.


## 새 주인공 (0.4)

현재 지도 주인공은 `characters/girl-sheet.png`, `characters/boy-sheet.png`를 사용합니다. `player/`의 이전 8장은 로딩 실패 시의 기본 캐릭터용으로 남겨 두었습니다.

선택창은 `characters/girl-portrait.png`, `characters/boy-portrait.png`를 사용합니다. 첨부 원본 4장의 픽셀은 수정하지 않았습니다.

도트 시트는 4열×4행입니다. 위에서부터 정면 대기, 정면 걷기, 오른쪽 걷기, 뒷모습 순입니다. 왼쪽은 오른쪽 그림을 뒤집습니다. 원본 시트 한 칸을 32×32로 표시하고, 프레임 바깥과 연결된 흰 배경·회색 안내선은 게임 화면에서 투명하게 처리합니다. 캐릭터 내부의 흰 눈동자는 유지합니다. 이동 중 120ms 간격으로 프레임을 넘깁니다.

**시트 파일을 교체한 뒤에는 `node build.mjs`를 실행하세요.** 로컬 HTML에서도 배경 처리가 작동하도록 시트를 코드에 함께 묶습니다. 전신 그림은 폴더형 `index.html`에서는 PNG 교체 후 새로고침만으로 적용됩니다. 단일 HTML은 변경 후 다시 빌드해야 합니다.
