# 독도 탐험대 — 맵 타일/캐릭터 일체형 개선 패키지 v2

참고: https://dokdo-nu.vercel.app/ (확인한 초기 화면: CHAPTER 01 동도 선착장, 2D/3D 전환, WASD/E, 동료·도감·공부 수첩 기능)

이 패키지는 **원본 사이트가 아니라 별도로 제작한 그래픽 에셋과 실행형 미리보기**다. Vercel 배포나 게임 소스코드를 변경한 것이 아니다.

## 우선 열어 볼 파일
1. `demo.html` — 브라우저에서 열기. 두 지도 전환, 남녀 캐릭터 전환, 방향키/WASD 이동, E 안내 메시지를 확인하는 독립 데모.
2. `preview_dokdo_v2.png` / `preview_ulleungdo_v2.png` — 1280×768 픽셀 화면 시안.
3. `characters_preview.png` — 원본 캐릭터의 5프레임 × 6행 정규화 결과.
4. `CLAUDE_COMMAND_KO.md` — 클로드에 복사할 정확한 기존 게임 연동 지시문.

### 캐릭터 애니메이션
- 남학생: 0행 아래 / 1행 오른쪽 / 2행 위
- 여학생: 3행 아래 / 4행 오른쪽 / 5행 위
- 각 방향 5프레임. 왼쪽은 오른쪽을 좌우 반전해서 그린다.
- 각 프레임은 64×72, 캐릭터 발끝 기준으로 anchor를 맞춘다.
- 원본(1024×1536)을 5×6으로 기계적으로 나누면 여백이 달라 프레임이 잘릴 수 있다. **정규화 아틀라스를 사용하라.**

### 맵 사용
`map_dokdo_v2.json`과 `map_ulleungdo.json`은 시연용이며 실제 지형·출입 허가 구역을 재현한 것이 아니다. 데모용 초기 플레이어 위치는 해당 JSON의 `playerSpawn`에 정의됨. 기존 실제 게임의 첫 씬과 이벤트 데이터가 우선이다.

- 타일 인덱스는 0부터, `sourceX=(id%columns)*32`, `sourceY=Math.floor(id/columns)*32`.
- `map.decorations`는 details_32.png의 index를 나타내며, 이동 충돌에는 영향을 주지 않는다.
- 오브젝트의 x/y 좌표는 타일 단위이며, 객체 너비/높이는 manifest 참조.
- 캐릭터는 발 중심 충돌만 검사하므로 머리가 절벽/나무에 살짝 겹칠 수 있고 Y축 정렬이 필요하다.
- `dd_flag`는 태극기 원본을 축소하여 정식 문양을 유지했으나, 작은 크기의 한계가 있으므로 교육 팝업은 원본을 직접 보여주는 게 낫다.
- `demo.html`은 JS에 맵 데이터를 내장해 로컬에서 열 수 있고, **메인 게임의 퀘스트와 저장 기능이 구현된 것은 아니다.**

## 진행 순서
1. 압축을 풀고 `demo.html`을 열어서 스타일·크기를 확인한다.
2. 실제 Claude 프로젝트 소스에 이 폴더를 첨부한다.
3. `CLAUDE_COMMAND_KO.md`의 전체 명령어를 클로드에 준다.
4. 클로드가 기존 게임 구조를 분석하여 새 아틀라스만 교체하게 한다.
5. 테스트 환경에서 저장·2D/3D·퀘스트 연결을 확인한 후 배포한다.

## 저작 및 사실성
지형/오브젝트 타일은 기존에 창작한 도트 아트 에셋을 기반으로 개선했으며, 캐릭터는 이 대화에서 사용자가 제공한 `explorers-atlas-v17.png`에서 직접 변환했다. 이전에 예시로 보인 포켓몬 상용 스프라이트를 그대로 복제한 파일은 포함되지 않는다.
