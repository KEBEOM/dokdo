# Aseprite로 주인공·김박사 고치기

v0.54부터 남학생, 여학생, 김박사는 **도트 PNG를 그대로** 게임에 그려요.
Aseprite에서 PNG를 고쳐 같은 이름으로 저장하면 게임에 그대로 나와요. 변환 스크립트는 따로 돌리지 않아도 돼요.

## 1. 고칠 파일

모두 `dist/assets/characters/sheets/` 폴더에 있어요.

| 파일 | 크기 | 쓰이는 곳 |
|---|---|---|
| `boy.png` · `girl.png` · `professor.png` | 160×120 | 지도에서 걷는 모습, 대화창 얼굴, 컷신 |
| `boy-portrait.png` · `girl-portrait.png` · `professor-portrait.png` | 128×128 | 캐릭터 고르기 창, 김박사 등장 컷신의 큰 그림 |

함께 쓰는 파일:
- `art/aseprite-guide.png`: 칸 경계, 가운데 줄, 발 줄을 그린 투명한 안내 그림(참고 레이어로 써요)
- `art/시트-미리보기.html`: 저장한 PNG를 끌어다 놓으면 게임처럼 걸어 보이고, 규칙에 맞는지 검사해요(인터넷 없이 열려요)

## 2. 걷기 시트의 규칙 (160×120)

한 칸은 **가로 32 × 세로 40 도트**예요. 칸을 가로 5개, 세로 3줄로 놓아요.

|  | 1칸 | 2칸 | 3칸 | 4칸 | 5칸 |
|---|---|---|---|---|---|
| **1줄: 아래(앞모습)** | 정지 | 걷기1 | 걷기2 | 걷기3 | 걷기4 |
| **2줄: 오른쪽** | 정지 | 걷기1 | 걷기2 | 걷기3 | 걷기4 |
| **3줄: 위(뒷모습)** | 정지 | 걷기1 | 걷기2 | 걷기3 | 걷기4 |

꼭 지켜 주세요:
1. **캔버스 크기는 160×120 그대로** 두어요. 칸을 늘리면 게임 그림이 어긋나요.
2. **발끝은 각 칸의 39번째 줄**에 닿게 해요. 맨 아래 40번째 줄(안내 그림의 빨간 줄)은 비워요. 게임은 이 줄을 땅으로 삼아요.
3. **몸의 가운데는 16번째와 17번째 도트 사이**예요(안내 그림의 파란 점선). 왼쪽으로 걸을 때는 2줄(오른쪽)을 거울처럼 뒤집어 그리기 때문에, 몸이 가운데에서 벗어나면 좌우로 걸을 때 몸이 출렁여요.
4. **반투명 픽셀은 쓰지 않아요.** 연필(B)로 그리고, 색의 알파는 255(완전 불투명)로 두어요. 지울 때는 지우개(E)를 써요.
5. 걷기1~4는 이 순서로 돌아요: 걷기1(한 발 앞) → 걷기2(지나감) → 걷기3(다른 발 앞) → 걷기4(지나감). 한 칸을 걸을 때 2장씩 나와요(한 장에 0.11초).
6. 지도 한 칸은 32도트예요. 지금 캐릭터의 키는 28~30도트쯤이에요. 머리 위에 10도트쯤 여유가 있어서, 모자를 높게 그려도 돼요.

> 큰 그림(128×128)은 칸 규칙이 없어요. 발이 아래쪽에 오도록 그리고, 크기만 128×128로 지켜 주세요.

## 3. 처음 한 번: Aseprite 준비

1. **파일 열기**: `File > Open`(Ctrl+O)으로 `boy.png`를 열어요.
2. **칸 격자 맞추기**: `View > Grid > Grid Settings`에서 X 0, Y 0, Width 32, Height 40으로 정해요. `View > Show > Grid`(Ctrl+')로 격자를 켜요.
3. **도트 격자 켜기**: `View > Show > Pixel Grid`(Ctrl+Shift+')를 켜요. 크게 확대하면 한 도트씩 보여요.
4. **안내 그림 깔기**: `Layer > New > New Reference Layer from File`로 `art/aseprite-guide.png`를 열어요. 빨간 줄은 땅, 파란 점선은 가운데예요. 참고 레이어는 맨 아래에 두어요.
5. **색 모으기**: 팔레트의 ≡ 메뉴에서 `New Palette from Sprite`를 누르면, 그림에 쓰인 색만 팔레트에 모여요. 같은 색으로 고치면 그림이 깔끔해요.
6. **연필 설정**: 연필(B)의 크기는 1로 두어요. 위쪽 설정 줄의 `Pixel-perfect`를 켜면 선이 깔끔해요. 색을 고를 때는 Alt+클릭(스포이트)을 써요.

## 4. 고치는 방법 A — 한 장으로 바로 고치기 (작은 수정에 추천)

얼굴, 옷 색, 머리 모양을 조금 고칠 때 써요.

1. 3단계처럼 PNG를 열고 격자와 안내 그림을 켜요.
2. 15칸을 직접 고쳐요. 한 칸을 고쳤으면, 같은 방향의 다른 4칸도 똑같이 고쳐 주세요(걸을 때 깜박이지 않게).
3. 저장하기 전에 **참고 레이어를 지우거나 눈 아이콘으로 꺼요.** PNG에는 보이는 레이어가 모두 합쳐져서 저장돼요.
4. `File > Save`(Ctrl+S)로 **같은 이름, 같은 폴더**에 PNG로 저장해요. 레이어가 합쳐진다는 안내가 나오면 그대로 확인을 눌러요.

> 레이어를 나눠 그리고 싶다면, 작업 파일은 `art/boy.aseprite`처럼 따로 저장해 두고, 게임용 PNG는 `File > Export As`로 `sheets/boy.png`에 내보내요.

## 5. 고치는 방법 B — 애니메이션으로 보며 고치기 (걷는 동작을 다시 그릴 때)

1. `File > Import Sprite Sheet`를 열어요.
   - 파일: `boy.png` · Type: **By Rows** · Width **32** · Height **40** · Padding 0 → `Import`
   - 15장의 프레임이 생겨요: 1~5 아래, 6~10 오른쪽, 11~15 위.
2. 프레임 길이를 맞춰요. 프레임 1~15를 모두 고르고 `Frame > Frame Properties`에서 **110ms**로 정해요(게임 속도).
3. 방향마다 태그를 달아요(`Frame > Tags > New Tag`): `아래-걷기` 2~5, `오른쪽-걷기` 7~10, `위-걷기` 12~15.
   태그를 고르고 재생하면 그 방향의 걷는 모습만 돌아요.
4. **어니언 스킨**(타임라인의 겹친 동그라미 버튼)을 켜면 앞뒤 프레임이 비쳐 보여서 발 위치를 맞추기 쉬워요.
5. 다 고쳤으면 `File > Export Sprite Sheet`로 다시 한 장으로 만들어요.
   - Layout: Sheet Type **By Rows** · Constraints **Fixed # of Columns: 5**
   - Borders: Border Padding·Spacing·Inner Padding 모두 **0**, `Trim Sprite`·`Trim Cels`는 **끄기**
   - Output: `Output File`에 `dist/assets/characters/sheets/boy.png` · `JSON Data`는 끄기
   - `Export`를 누르면 160×120 PNG가 돼요.
6. 이 애니메이션 파일은 `art/boy-walk.aseprite`로 저장해 두면, 다음에 3번부터 이어서 고칠 수 있어요.

## 6. 확인하기

1. **미리보기**: `art/시트-미리보기.html`을 브라우저로 열고, 저장한 PNG를 끌어다 놓아요. 네 방향으로 걷는 모습과 검사 결과가 나와요.
   - 초록 ✓만 나오면 좋아요. 빨간 !가 나오면 그 안내대로 고쳐요(크기, 반투명, 빈 칸, 발 위치).
2. **게임에서 보기**(셋 중 편한 것)
   - 내 컴퓨터에서 바로 보기: 게임 폴더에서 `python -m http.server 8000`을 실행하고 http://localhost:8000/dist/ 를 열어요. PNG를 저장할 때마다 **Ctrl+F5**로 새로고침해요(그냥 새로고침하면 옛 그림이 남아 있을 수 있어요).
   - 한 파일 판(`dokdo-explorers-offline.html`)을 다시 만들려면 Node.js를 설치하고, 게임 폴더에서 `node scripts/build-offline.mjs`를 실행해요.
   - 고친 PNG를 Claude에게 보내 주면, 다음 판에 넣어 검사까지 마쳐 드려요.

## 7. 자주 하는 실수

| 이렇게 보이면 | 까닭과 고치는 법 |
|---|---|
| 게임에서 캐릭터가 땅에 묻히거나 떠 있어요 | 발끝이 39번째 줄이 아니에요. 빨간 줄 바로 위에 발을 맞춰요. |
| 왼쪽으로 걸을 때만 몸이 옆으로 밀려요 | 오른쪽 줄의 몸이 가운데(16·17번째 도트 사이)에서 벗어났어요. |
| 걸을 때 한 장만 튀어요 | 그 칸만 크기나 위치가 달라요. 어니언 스킨으로 앞뒤 칸과 맞춰요. |
| 테두리가 흐릿하거나 회색 테가 생겨요 | 반투명 픽셀이 있어요. 연필로 다시 칠하고, 브러시나 흐림 도구는 쓰지 않아요. |
| 그림이 통째로 어긋났어요 | Export할 때 Trim이 켜져 있었거나 Padding이 0이 아니었어요. 5단계 설정을 다시 확인해요. |
| 참고 그림의 빨간 줄이 게임에 보여요 | 저장할 때 참고 레이어가 켜져 있었어요. 끄고 다시 저장해요. |
