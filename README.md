# 독도 탐험대 v0.37 — GitHub 업로드용

코드, 이미지, 학습 데이터, 테스트가 포함된 정적 JavaScript 게임입니다.
학생 로그인이나 Supabase, API 키가 필요하지 않습니다.

## 업로드
1. ZIP을 컴퓨터에서 압축 해제합니다.
2. 새 GitHub 저장소(또는 기존 저장소)에 압축을 푼 **내용물 전체**를 올립니다.
3. 최상위에 index.html, package.json, vercel.json, dist 폴더가 있어야 합니다.
ZIP 파일 자체만 올리면 게임이 실행되지 않습니다. 파일이 많으면 GitHub Desktop으로 폴더 전체를 커밋·푸시하세요.

## 배포
- GitHub Pages: main 브랜치의 최상위(root) 폴더를 게시 대상으로 사용합니다. 최상위 index.html이 dist/ 게임으로 연결됩니다.
- Vercel: 이 저장소를 연결하고 정적 사이트로 배포합니다. vercel.json이 출력 폴더를 dist로 지정합니다. 별도 빌드 명령은 없습니다.

## 내 컴퓨터에서 실행
**가장 쉬운 방법: `dokdo-explorers-offline.html`을 더블클릭하세요.** 코드와 그림이 모두 한 파일에 들어 있어서 인터넷이나 서버 없이 열립니다. 이 파일만 USB나 메일로 옮겨도 됩니다.

`dist/index.html`이나 최상위 `index.html`을 더블클릭하면 게임이 열리지 않습니다. 브라우저가 보안 때문에 컴퓨터 안의 파일(file://)에서 JavaScript 모듈을 불러오지 못하게 막기 때문입니다. 이 파일들은 GitHub Pages·Vercel 같은 웹 주소에 올렸을 때 쓰는 파일입니다.

코드나 그림을 고친 뒤에는 `node scripts/build-offline.mjs`로 한 파일짜리 게임을 다시 만드세요.

dist 폴더를 그대로 열어 보고 싶다면, Python이 설치된 컴퓨터에서 이 폴더를 열고 다음을 실행한 뒤 브라우저에서 http://localhost:8000 을 엽니다.

    python -m http.server 8000

- scripts/villain-dots.json: 백무단 도트 원본(글자 하나 = 도트 하나)
- scripts/design-monsters.py: 그림이 없던 우산몬 78종(20~65, 68~99번)을 그리는 도트 생성기(색·모양 값을 고치고 다시 실행)

기존 구현 범위와 학습 자료 출처는 PROJECT-NOTES.md에 있습니다.
수업 기록과 게임 진행은 각 브라우저에 저장됩니다. 다른 주소로 옮길 때에는 게임 메뉴의 저장 파일 내보내기/가져오기를 사용하세요.

  - 오프닝: 울릉도와 독도 곳곳에 우산몬이 나타나고, 울릉도에서 수상한 공사가 시작돼요(새 위기 장면 `panel:dig`).
  - 1장 도동항: 뒷산의 몽땅랜드 공사 가림막(7번 표지), 주민들의 공사 이야기, 상자 속 쪽지 ‘다음 공사지: 독도’.
  - 배 위: 몽땅랜드 배도 독도로 갔다는 김박사의 말.
  - 대한봉: 백무가 지우개 기계를 처음 울릉도에서 시험해서 울릉도에도 우산몬이 있었다는 진실, 두 섬을 묶은 테마파크 설계도.
  - 엔딩: 다시 도동항. 울릉도 공사가 멈추고 숲에 나무를 다시 심어요.
- **제4의 벽을 깨는 대사:** 조작법·메뉴·노란 표시를 말하는 인물(김박사, 나루, 연구 안내원)이 마지막에 “어라? 방금 누구한테 말한 거죠?”처럼 재치 있게 넘어가요.
- **실제를 닮은 마을 배치(scripts/layout-towns.py → dist/maps.js):**
  - 도동항: 골짜기 입구의 항구. 방파제와 빨간 등대, 바닷가 여객터미널(상점), 골짜기를 따라 올라가는 길, 왼쪽 절벽 아래 행남 해안산책로, 뒷산 공사 터.
  - 우산봉(동도): 평평한 정상에 등대(연구소)와 경비대(수호관), 헬기장, 분화구(천장굴), 선착장에서 올라오는 돌계단.
  - 탕건봉(서도): 바닷가 주민숙소(상점) 뒤로 정상까지 가파른 계단(약 998계단), 뾰족한 바위 봉우리.
  - 물골(서도 북서쪽): 계단을 내려가면 몽돌 해안과 콘크리트로 둘러싼 샘.
  - 한반도바위·가제바위·코끼리바위·대한봉: 오르막길을 돌계단으로.
  - 새 지도 글자: `^` 돌계단, `K` 헬기장(3×3), `;` 몽돌 해안, `l` 방파제 등대, `n` 공사 가림막.
- **이름표:** 다른 캐릭터를 가리지 않도록, 사람 이름은 2칸 안에서 가장 가까운 한 명만 머리 위 말풍선으로 보여 줘요. 건물 이름은 문 앞 3칸 안에 오면 문 위 나무 간판으로 나타나요. 대화 중에는 모두 숨어요.
- **결투 화면(휴대폰 최적화):** 우산몬 크기를 무대의 가로·세로 중 좁은 쪽에 맞춰서, 세로로 긴 아이폰에서도 내 우산몬이 상대나 몽땅랜드 직원을 덮지 않아요. 휴대폰에서는 상태 창의 작은 그림을 숨겨 이름·Lv·HP 막대가 창 안에 들어가고, 명령 창의 설명은 이름 아래 작은 줄로 내려가요.
- **상대 게이지는 수치로:** ‘검은 기운 32 / 54’처럼 남은 양과 처음 양을 보여 줘요(관장 결투의 ‘기운’도 같아요).
- **몽땅랜드 직원은 결투를 시작할 때 한 번만** 큰 그림으로 나와요. 다음 우산몬을 내보낼 때는 우산몬만 나와요.
- 지명과 시설의 대략적인 위치만 참고했어요. 섬 모양·건물 수·마을은 게임용 창작이에요.

  - 독도: 하얀 등대가 붙은 관측소(연구소, 동도 등대 느낌) · 태극기가 있는 경비대 숙소 같은 2층 건물(수호관) · 바위에 기대어 선 하얀 3층 건물(쉼터, 서도 주민숙소 느낌) · 그물과 부표가 걸린 어업인 집
- **입체감과 원근감**
  - 한 칸 = 32×32 도트(게임 1픽셀 = 도트 1개)로, 위에서 비스듬히 내려다본 3/4 시점이에요.
  - 지붕의 경사면과 윗면, 오른쪽 옆벽, 처마 그림자, 창문 깊이와 반사, 문 앞 디딤돌, 땅 그림자를 넣었어요. 빛은 왼쪽 위에서 와요.
  - 문은 언제나 가운데 칸 위에 있어요.
- **소나무를 치웠어요.**
  - 울릉도는 후박나무와 동백나무(빨간 꽃)예요.
  - 독도는 키 큰 나무가 자라지 않으니 사철나무 덤불과 해국 덤불로 바꿨어요.
  - 기와를 얹은 돌담은 울릉도에서는 돌담, 독도에서는 탐방로 나무 난간으로 바꿨어요. 탐험 기록판도 기와 없는 나무 게시판이에요.
