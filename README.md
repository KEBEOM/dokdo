# 독도 탐험대 v0.28 — GitHub 업로드용

코드, 이미지, 학습 데이터, 테스트가 포함된 정적 JavaScript 게임입니다.
학생 로그인이나 Supabase, API 키가 필요하지 않습니다.

## 업로드
1. ZIP을 컴퓨터에서 압축 해제합니다.
2. 새 GitHub 저장소(또는 기존 저장소)에 압축을 푼 **내용물 전체**를 올립니다.
3. 최상위에 index.html, package.json, vercel.json, dist 폴더가 있어야 합니다.
ZIP 파일 자체만 올리면 게임이 실행되지 않습니다. 파일이 많으면 GitHub Desktop으로 폴더 전체를 커밋·푸시하세요.

## 배포
- GitHub Pages: main 브랜치의 최상위(root) 폴더를 게시 대상으로 사용합니다. 최상위 index.html이 dist/ 게임으로 연결됩니다.
- Vercel: 이 저장소를 연결하고 정적 사이트로 배포합니다. vercel.json이 출력 폴더를 dist로 지정합니다. 별도 빌드 명령은 없습니다.

## 내 컴퓨터에서 실행
Python이 설치되어 있다면 이 폴더에서:

    python -m http.server 8000

브라우저에서 http://localhost:8000 을 엽니다. dist/index.html을 더블클릭하면 JavaScript 모듈의 로컬 파일 제한 때문에 작동하지 않을 수 있습니다.

## 수정할 파일
- dist/story.js: **오프닝 컷신·김박사 안내·지역 도착 장면의 대사와 연출** (쉽게 고칠 수 있게 데이터로 분리)
- dist/maps.js: **15개 지도(마을 8 + 길 7)의 모양, 지명, 표지판·인물·상자 등** (글자 그림으로 편집)
- dist/game.js: 화면과 게임 진행, 맵 이동, 드래곤 퀘스트식 전투 진행
- dist/battle-ui.js: 전투 창(명령·메시지·문제) 화면
- dist/cutscene.js: 컷신 재생기(타이핑, ▼, 페이드, 선택지, 건너뛰기)와 장면 배경 그림
- dist/world.js, dist/terrain.js, dist/props.js: 지도 그리기, 지형, 작은 소품 도트
- dist/data.js, dist/learning.js: 독도몬·이야기·학습 문항
- dist/assets/: 이미지 (백무단 시트: assets/characters/villain-*-v25.png, 좌표: dist/villain-atlases.js)
- scripts/villain-dots.json: 백무단 도트 원본(글자 하나 = 도트 하나)
- scripts/design-monsters.py: 그림이 없던 독도몬 78종(20~65, 68~99번)을 그리는 도트 생성기(색·모양 값을 고치고 다시 실행)
- scripts/import-portraits.py: 백무단 전투 등장 그림 가져오기(부하·간부·보스 순서), 결과는 dist/assets/characters/baekmudan-*-portrait.png
- scripts/import-monsters.py: 독도몬 그림 가져오기(정면 + 뒷모습 자동 생성), scripts/monster-backs.json: 뒷모습 설정
- scripts/bake-villains.mjs: 백무단 시트 생성기(색·두건·간부 코트를 고치고 다시 실행)
- docs/story-maps-v22.md: 지도·컷신 수정 방법

기존 구현 범위와 학습 자료 출처는 PROJECT-NOTES.md에 있습니다.
수업 기록과 게임 진행은 각 브라우저에 저장됩니다. 다른 주소로 옮길 때에는 게임 메뉴의 저장 파일 내보내기/가져오기를 사용하세요.

## 개발 검사
Node.js 설치 후:

    npm install
    npm test                      # 엔진·지도·대본·그림·캐릭터·앞뒤 가림·NPC 이동 검사
    npx playwright install chromium
    npm run test:flow             # 실제 브라우저로 오프닝부터 엔딩까지 진행 (약 4분)

## 이 버전의 변경 (0.28)
- 그림이 없던 독도몬 78종(보리밥나무, 곤충 13, 물고기 18, 바다 생물·해조류 14, 새 32)을 새로 그렸습니다. 사용자 그림과 같은 귀여운 도트체(진한 외곽선, 큰 눈과 반짝임, 볼 터치)이고, 뒷모습도 함께 만들었습니다. 이제 100종 모두 그림이 있습니다.
- 사철나무와 강치는 전설의 독도몬으로, 게임 전체에 한 마리씩만 있습니다. 사철나무는 천장굴 길의 ‘오래된 사철나무’에서 한 번만 정화해 동료로 맞이합니다(독도의 사철나무, 천연기념물 제538호). 강치는 지금처럼 대한봉 이야기 끝에 만납니다.
- 스타팅 독도몬(해국·괭이갈매기·독도새우)도 게임 전체에 한 마리씩입니다. 고른 한 마리 말고는 풀숲·관장·백무단 어디에도 나오지 않습니다(대한봉 관장 팀은 매·참문어·방어로 바꿨습니다).
- 풀숲 위에 서 있던 야생 독도몬을 없앴습니다. 광포화된 독도몬은 풀숲을 걸을 때 갑자기 나타납니다.
- 사용자가 그린 그림이 생기면 `scripts/import-monsters.py`로 넣으면 생성된 그림을 덮어씁니다.

### 독도몬 그림 더 넣기
1. 그림 파일 이름을 `번호 이름.jpg`(또는 .png)로 맞춰 한 폴더에 모읍니다. 예: `20 보리밥나무.jpg`. 번호는 `dist/data.js`의 독도몬 번호입니다.
2. `pip install pillow numpy` 후 `python scripts/import-monsters.py <폴더>`를 실행합니다.
3. 정면은 `dist/assets/monsters/020.png`, 뒷모습은 `dist/assets/monsters/back/020.png`로 저장됩니다.
4. 뒷모습은 눈을 자동으로 찾아 지우고 좌우를 뒤집어 만듭니다. 어색하면 `scripts/monster-backs.json`에 얼굴 영역(`face`)을 적거나, 옆을 보는 독도몬은 `"side": true`로 두고 다시 실행하세요. 뒷모습 그림을 직접 그렸다면 `back/` 폴더에 같은 이름으로 넣으면 됩니다.
