# 독도 탐험대 v0.91 — GitHub 업로드용

코드, 이미지, 학습 데이터, 테스트가 포함된 정적 JavaScript 게임입니다.
학생 로그인이나 Supabase, API 키가 필요하지 않습니다.

## 업로드
1. ZIP을 컴퓨터에서 압축 해제합니다.
2. 새 GitHub 저장소(또는 기존 저장소)에 압축을 푼 **내용물 전체**를 올립니다.
3. 최상위에 index.html, package.json, vercel.json, dist 폴더가 있어야 합니다.
ZIP 파일 자체만 올리면 게임이 실행되지 않습니다. 파일이 많으면 GitHub Desktop으로 폴더 전체를 커밋·푸시하세요.

## 배포
- GitHub Pages: main 브랜치의 최상위(root) 폴더를 게시 대상으로 사용합니다. 최상위 index.html이 dist/ 게임으로 연결됩니다.
- Vercel: 이 저장소를 연결하고 정적 사이트로 배포합니다. vercel.json이 출력 폴더를 dist로 지정합니다. 별도 빌드 명령은 없습니다.

## 내 컴퓨터에서 실행
**가장 쉬운 방법: `dokdo-explorers-offline.html`을 더블클릭하세요.** 코드와 그림이 모두 한 파일에 들어 있어서 인터넷이나 서버 없이 열립니다. 이 파일만 USB나 메일로 옮겨도 됩니다.

`dist/index.html`이나 최상위 `index.html`을 더블클릭하면 게임이 열리지 않습니다. 브라우저가 보안 때문에 컴퓨터 안의 파일(file://)에서 JavaScript 모듈을 불러오지 못하게 막기 때문입니다. 이 파일들은 GitHub Pages·Vercel 같은 웹 주소에 올렸을 때 쓰는 파일입니다.

코드나 그림을 고친 뒤에는 `node scripts/build-offline.mjs`로 한 파일짜리 게임을 다시 만드세요.

dist 폴더를 그대로 열어 보고 싶다면, Python이 설치된 컴퓨터에서 이 폴더를 열고 다음을 실행한 뒤 브라우저에서 http://localhost:8000 을 엽니다.

    python -m http.server 8000

## 이 버전의 변경 (0.91) — 잠수 벽 · 잠수 중 우산몬 · 또렷한 도트
- **잠수 중엔 물 밖이 벽**: 바닷속에서 땅·부두·물가로 가면 벽에 막힌 것처럼 멈추고 ‘물 위로(Q)로 올라와요’ 안내가 떠요. 올라오기는 Q로만(예전엔 물 경계에 닿으면 저절로 올라왔어요). 길 안내도 잠수 중엔 올라온 뒤에.
- **잠수 중 상호작용**: 헤엄치는 야생·친구 우산몬과 바닷속에서도 결투·만나기(예전엔 잠수 중 E가 바닷속 그림만 봤어요). 바닥 우산몬은 바로 앞이 아니어도 둘레 한 칸(대각선 포함)이면 살펴봐요. 헤엄치는 물고기 우산몬은 화면에 보이는 자리(바닥에서 떠 있는 만큼 위로 보여요) 가까이서도 살펴봐요.
- **지도 우산몬 도트를 또렷하게**(`scripts/make-monster-dots.py` → `assets/monsters/dots.png`, `dist/monster-dots.js`): 512 그림을 44px로 줄이면 도트가 빠지거나 굵기가 들쭉날쭉했어요. 그림마다 도트 칸 크기(5~20px)와 시작 자리를 찾아 원래 도트 그림으로 되돌리고, 정수 배(1도트 = 1·2·3px)로 만들어 1:1로 그려요. 도감·결투는 512 그림 그대로.
- **HD-2D 도트 굵기 고르게**: 카메라 거리를 살짝 맞춰 내 자리에서 지도 1px이 화면 정수 px(1·2·3…)이 되게(굵기가 2px·3px 섞이지 않게). 화면 위아래 흐림(심도)은 화면 끝에만 약하게.

## 지난 변경 (0.65) — 결투 아래 창: 한 번에 한 가지만

- **문제 화면**: 차례 칩 하나(✎ 기록 찾기 / 🛡 막기) + 상성 배지(있을 때만) + 문제 + 보기. 규칙 문장은 김박사의 연습 대결에서만 나와요. 힌트는 ‘💡 힌트’ 단추.

- **명령 단추**: 그림과 이름만. 고른 단추의 설명 한 줄(상성, 성공률, 회복젤 수)은 오른쪽 말 창에 나와요.
- **말 창**: 결투를 시작할 때 넘기던 문장을 한 번으로 합쳤어요.
- 고친 곳: battle-ui.js(quiz, reveal, explain, menu), game.js(askQuiz, attackWithQuiz, enemyTurn, runBattle), style.css 맨 끝
