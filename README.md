# 독도 탐험대 v0.47 — GitHub 업로드용

코드, 이미지, 학습 데이터, 테스트가 포함된 정적 JavaScript 게임입니다.
학생 로그인이나 Supabase, API 키가 필요하지 않습니다.

## 업로드
1. ZIP을 컴퓨터에서 압축 해제합니다.
2. 새 GitHub 저장소(또는 기존 저장소)에 압축을 푼 **내용물 전체**를 올립니다.
3. 최상위에 index.html, package.json, vercel.json, dist 폴더가 있어야 합니다.
ZIP 파일 자체만 올리면 게임이 실행되지 않습니다. 파일이 많으면 GitHub Desktop으로 폴더 전체를 커밋·푸시하세요.

## 배포
- GitHub Pages: main 브랜치의 최상위(root) 폴더를 게시 대상으로 사용합니다. 최상위 index.html이 dist/ 게임으로 연결됩니다.
- Vercel: 이 저장소를 연결하고 정적 사이트로 배포합니다. vercel.json이 출력 폴더를 dist로 지정합니다. 별도 빌드 명령은 없습니다.

## 내 컴퓨터에서 실행
**가장 쉬운 방법: `dokdo-explorers-offline.html`을 더블클릭하세요.** 코드와 그림이 모두 한 파일에 들어 있어서 인터넷이나 서버 없이 열립니다. 이 파일만 USB나 메일로 옮겨도 됩니다.

`dist/index.html`이나 최상위 `index.html`을 더블클릭하면 게임이 열리지 않습니다. 브라우저가 보안 때문에 컴퓨터 안의 파일(file://)에서 JavaScript 모듈을 불러오지 못하게 막기 때문입니다. 이 파일들은 GitHub Pages·Vercel 같은 웹 주소에 올렸을 때 쓰는 파일입니다.

코드나 그림을 고친 뒤에는 `node scripts/build-offline.mjs`로 한 파일짜리 게임을 다시 만드세요.

dist 폴더를 그대로 열어 보고 싶다면, Python이 설치된 컴퓨터에서 이 폴더를 열고 다음을 실행한 뒤 브라우저에서 http://localhost:8000 을 엽니다.

    python -m http.server 8000

- docs/story-maps-v22.md: 지도·컷신 수정 방법

기존 구현 범위와 학습 자료 출처는 PROJECT-NOTES.md에 있습니다.
수업 기록과 게임 진행은 각 브라우저에 저장됩니다. 다른 주소로 옮길 때에는 게임 메뉴의 저장 파일 내보내기/가져오기를 사용하세요.

## 이 버전의 변경 (0.47) — 나리분지 초원에서 첫 동료 고르기 · 글자 정리

- 오프닝이 끝나면 **울릉도 나리분지 초원**(울릉도에서 가장 넓은 평지)으로 가요. 김박사가 미리 데려다 놓은 **우산몬 30마리**가 초원을 자유롭게 걸어 다녀요.
- 직접 돌아다니며 우산몬에게 다가가 말을 걸면(E·스페이스·‘대화’ 단추, 또는 우산몬을 누르기) 카드가 열려요. 속성과 분류, 체력·공격·방어·스피드, 강한 속성과 약한 속성, 첫 관장 해온과의 상성을 보고 **「이 친구를 동료로 데려갈래요」** 또는 **「조금 더 둘러볼래요」**를 골라요.
- 30마리는 전설의 우산몬(천연기념물 6종 · 사철나무 · 강치)을 뺀 92종 가운데 매번 다르게 뽑혀요. 초원에서 저장하고 이어 해도 같은 친구들이 그대로 있어요.
- 데려간 친구는 **Lv6**에서 시작해요. 92종 모두 첫 관장을 혼자 이길 수 있는지 `tests/balance.test.mjs`가 확인해요. 동료를 정하면 김박사의 안내를 듣고 도동항에서 연습 결투부터 모험이 시작돼요.
- 예전 스타팅이던 해국·괭이갈매기·독도새우도 이제 초원과 길에서 만날 수 있어요.
- 오프닝에서 우산몬이 **풀숲에서 튀어나오던 연출을 없앴어요**. 괭이갈매기가 풀밭에 그냥 서 있어요.
- 풀밭 장면(오프닝 · 첫 동료 · 전설의 우산몬)의 흙길을 없애고 **온통 풀밭**으로 바꿨어요(`scenery/cutscene-art-v47.png`).
- **속성을 독도의 자연을 닮은 다섯 가지로**: 파도 → 바위 → 바람 → 풀 → 빛 → 파도. 화살표 앞의 속성이 뒤의 속성에 강해요(강한 상대에게 정답 1.5배, 약한 상대에게 0.75배).
  - 파도 → 바위: 파도가 바위를 깎아 독립문바위·천장굴 같은 모양을 만들었어요.
  - 바위 → 바람: 바위가 거센 바닷바람을 막아 줘요.
  - 바람 → 풀: 거센 바닷바람 때문에 독도의 풀과 나무는 키가 작아요.
  - 풀 → 빛: 풀은 햇빛을 받아 양분을 만들어요(광합성).
  - 빛 → 파도: 햇볕이 바닷물을 데워 수증기로 날려 보내요(물의 순환).
  - 메아리 속성은 없앴어요. 참문어→바위, 보석말미잘→빛, 아비·강치→파도, 소쩍새·호랑지빠귀·개똥지빠귀→바람으로 바꿨고, 잠수하는 가마우지 두 종은 파도, 빛깔이 고운 꾀꼬리·물총새·청호반새·후투티는 빛으로 옮겨 다섯 속성을 고르게 나눴어요. ‘잎’은 ‘풀’로 이름을 바꿨어요.
  - 탕건봉(윤서)은 바람 수호관(꺅도요·검은가슴물떼새·꼬까도요), 대한봉(가온)은 바위 수호관(바위게·보라성게·참문어)이 됐어요.
  - 속성 고리와 까닭은 메뉴 → 도움말, 첫 동료 카드, 김박사 안내에서 볼 수 있어요. 고리는 `dist/engine.js`의 `TYPE_RING`·`TYPE_REASON`에서 고쳐요.
- **새로 찍은 도트**: 001 해국, 009 갯제비쑥, 014 왕김의털, 017 왕호장근, 018 사철나무를 새 그림으로 바꿨어요. 사철나무는 새 그림이 노멀폼(018-1)이고 예전 그림이 변환폼(018-2)이 되어, 다른 전설의 우산몬처럼 결투에서 **형태변환**을 쓸 수 있어요(전설 7종 모두 두 가지 모습). 원본은 `dist/assets/monsters-original/`에 있어요.
- **글자 정리**: 단추·이름·제목·카드 글자는 가운데 정렬하고, 짧은 글자는 한 줄에 들어가게 했어요. 대사(대화창·컷신·결투 대사창)만 왼쪽 정렬이에요. 한국어 낱말이 줄 끝에서 쪼개지지 않아요. 결투 단추 설명도 줄였어요(예: 「성공률 45%」, 「바람 → 빛 · 유리」).
- 고치는 곳: 초원 지도와 김박사·안내판은 `dist/maps.js`의 `STARTER_MEADOW`, 초원에 나올 수 있는 종과 레벨은 `dist/data.js`의 `starterPool`·`STARTER_LEVEL`, 카드는 `dist/game.js`의 `meetFriend`.

## 지난 변경 (0.46) — 한국풍 화면 (한지 · 나무 · 단청)

- 모든 창과 대화상자를 **한지 바탕 + 짙은 나무 테 + 위쪽 단청 띠**(녹·주홍·쪽빛·황)로 바꿨어요.
- 말하는 사람 이름표, 지역 알림, 제목 「독도 탐험대」는 **나무 현판**(금빛 글씨, 명조 계열 글꼴)이에요.
- 결투 명령은 **족자**: 위아래 나무 축, 늘어진 풍대, 가운데 한지에 명령 띠지를 붙이고 왼쪽에 오방색 **낙관(도장)** 아이콘을 찍었어요.
- 결투 대사창은 **나전칠기**(검은 옻칠 바탕에 자개 테), 문제의 답은 한지 띠, 번호는 쪽빛 도장이에요.
- 큰 버튼은 다홍 도장색, 맞힌 답은 청록, 틀린 답은 주홍이에요.
- 가로로 눕힌 휴대폰에서는 족자를 납작하게 줄여 명령 세 줄이 스크롤 없이 다 보여요.
- 색과 무늬는 `dist/style.css` 맨 아래 「v0.46 한국풍 화면」 묶음의 변수(`--hj`, `--wood`, `--band` 등)만 고치면 한꺼번에 바뀌어요.

## 지난 변경 (0.45) — 도감 별 표시 · 독도를 닮은 바위 들판
- **도감:** 아직 못 만난 우산몬은 검은 실루엣, 발견하거나 결투한 우산몬은 원래 모습으로 보여요. **동료로 만든 우산몬은 카드 왼쪽 위에 도트로 찍은 작은 별(★)**이 붙어요.
- **풀숲을 없앴어요.** 독도의 지도에서는 풀숲 자리가 **바위 들판**이 됐어요. 화산 응회암 땅에 금이 가 있고 자갈·이끼와 가끔 해국(보라)·땅채송화(노랑)가 피어 있어요(scripts/draw-terrain-bw.py의 `rocky`). 길에서는 야생 우산몬이 이 바위 들판과 잔디 위를 걸어 다녀요.
- **울릉도(도동항)**의 풀숲 자리는 푸른 잔디가 됐어요.
- 바위 덩어리 가장자리에 풀 테두리가 잘못 그려지던 것을 고쳤어요.
- 코드 주석과 문서에서 다른 게임 이름을 지우고 우리 표현으로 바꿨어요(출품용 정리).

## 지난 변경 (0.44) — 관장 난이도 · 정화할 때마다 받는 경험치
- **관장이 약해졌어요:**
  - 인증 결투의 관장 우산몬 레벨을 그 장 기준보다 2 낮췄어요(다시 대련은 그대로). 관통 확률도 30% → 15%.
  - 상대가 문제로 공격하는 위력을 0.6배로 낮췄어요(engine.js `ENEMY_POWER`, 난이도 손잡이).
  - **관장 팀을 수호관 속성에 맞춰 직접 골랐어요**(data.js `GYM_TEAMS`): 해온=파도 물고기, 소라=바람 맹금류, 단우=바위 물고기, 윤서=메아리, 초림=잎 식물, 시온=빛 곤충, 도하=파도 물고기, 가온=메아리. 예전엔 대부분 새였어요.
  - **1장 해온은 어느 스타팅에게도 상성이 나쁘지 않은** 자리돔·벵에돔만 내보내요. 예전엔 조피볼락(바위)이 괭이갈매기(바람)에게 상성이 좋아서, 다 맞혀도 이길 수 없었어요.
  - 확인(tests/balance.test.mjs): 정답을 60%만 맞혀도 스타팅 하나로 1장 관장을, 동료 셋이면 모든 관장을 이길 수 있어요.
- **경험치는 결투가 끝날 때가 아니라, 상대 우산몬을 정화하거나 동료로 만들 때마다** 받아요(engine.js `xpForDefeat`).
  - 받는 양 = 내 레벨에서 다음 레벨까지 필요한 경험치의 35% × (상대 레벨 ÷ 내 레벨). 한 번에 다음 레벨 필요량의 150%까지.
  - 결투에 나와 있던 동료는 전부, 나머지 동료는 절반을 받아요. 결투가 끝나면 조사 코인만 받아요.
  - 관장 인증을 받으면 동료 레벨이 그 장의 최소 레벨까지 오르는 인증 보너스는 그대로 있어요.

## 지난 변경 (0.43) — 길 위를 걸어 다니는 야생 우산몬
- **마을에는 야생 우산몬이 나오지 않아요.** 풀숲을 걸어도 갑자기 결투가 시작되지 않아요.
- **마을과 마을 사이의 길(7곳)**에서는 사나워진 우산몬 4마리가 잔디(평야)와 풀숲(들판) 위를 눈에 보이게 걸어 다녀요(dist/roamers.js).

  - **부딪히거나 눌러서 다가가면 결투**가 시작돼요. 그 길과 다음 장의 야생 우산몬이 나와요(전설·스타팅 제외).
